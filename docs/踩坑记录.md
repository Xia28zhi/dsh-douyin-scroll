# 踩坑记录（真机摸出来的）

这份笔记记的是「抖音网页版到底长什么样、自动化会在哪儿翻车」，全部来自真机 CDP 实测，不是推测。
对应代码在 `lib/act.mjs`（点按）、`lib/cdp.mjs`（浏览器起法）、`lib/vision.mjs`（视觉模型）、`index.js`（宿主）。

复跑证据：`../proof/probe-dom.mjs`（打印下面这些 DOM 事实）、`../proof/verify-comment.mjs`（真发带 @ 的评论）、`../proof/verify-share.mjs`（真分享）。

## 二、八个真翻过的坑

1. **悬停 ≠ 点击**。分享/更多这类 hover 弹层，`element.click()` 和 `Input.dispatchMouseEvent` 的 `mousePressed` 都没用，必须发 `mouseMoved` 并停一下。
2. **元素可能在折叠线以下**。按 `getBoundingClientRect()` 拿到的坐标点下去，点中的是视频画面（视口 1178×778，坐标 675 已经在可视区边缘）。要先 `scrollIntoView({block:'center'})`，再按新坐标点。
3. **「包含文本 + 面积最小」会挑到内层 span**。点不动。要挑「第一个自己就是可点元素（`button`/`svg`/`[role=button]`）」的那个。
4. **清空 Draft.js 编辑器不能直接改 innerHTML**。`document.execCommand('selectAll')` + `insertText` 才好使；直接设 `innerHTML=''` 会让后续输入丢失、React 状态错乱。
5. **`--headless=new` 的 Chrome/Edge 也能跑真实登录态**。抖音认的是 cookie + UA，不认有没有窗口；但**掉落登录态**（`Uifid` 过期）时表现为「评论框找不到 / 搜索 0 命中」，别先怪选择器。
6. **浏览器别反复新起**。`user-data-dir` 每次新建 ⇒ 登录态全丢、风控当新设备。要用固定的 `$DSH_HOME/douyin-duty/browser`，端口先探活再复用（`pickPort`）。
7. **提权/非提权**。Edge 已在提权进程里存在时，普通权限再启会弹「现有实例正在以提升的权限运行」并被拦 —— 这时**只能连它已经开的 CDP 端口**（默认 9333），不要试图自己拉起。
8. **视觉模型要 `max_tokens` 给够**。给 32 会被 `reasoning_content` 占满、正文为空；`GLM-5.3-Flash` 实测 500 才能稳定出一句中文描述，3000 才稳。

## 三、插件的选择器维护策略

- 所有选择器**只集中在 `lib/act.mjs` 一个 `SEL` 常量里**，改一处即可。
- 每个动作都有「找不到就 dry-run 返回原因」的分支，不许静默失败。
- 真发前一律 `dryRun: true` 跑一遍，`duty.log` 里能看到「点了/没找到/退化了」。

## 四、附：真的被风控拦过

- 连续 4 轮评论后，第 5 轮开始出现「操作频繁」弹窗，页面元素全在但点不动。
- 应对：`lib/guard.mjs` 检测验证码/风控文案 → 中止本轮、写报告、**不重试**；评论配额由 `outbox.jsonl` 里 `status:'sent'` 的条数统计（`recordSent`）。
- 结论：**宁可少发，别硬怼**。被限流的账号恢复要几天，而插件一天不刷不亏。
